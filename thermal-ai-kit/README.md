# Thermal AI Kit

This project provides a comprehensive toolkit for thermal image analysis, including ingestion, detection, postprocessing, and API modules. It also features a user interface for easy interaction.

## Modules

- **Ingestion:** Handles the input of thermal imaging data.
- **Detectors:** Contains various detection models, including Y8 Thermal and C2Former.
- **Postprocessing:** Processes detection results for further analysis.
- **API:** Provides an interface for programmatic access to the toolkit's functionalities.
- **UI:** Offers a user-friendly graphical interface.

## Quickstart

To get started with the Thermal AI Kit, please refer to the `quickstart.sh` script.

## Docker Compose

The project uses Docker Compose for easy deployment. The `compose.yaml` file defines the services and configurations.
