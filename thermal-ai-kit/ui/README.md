# UI Module

This module is responsible for the user interface of the thermal AI kit.

## SvelteKit Project
This directory is intended for a SvelteKit front-end application.
To initialize a new SvelteKit project here (if not already done):
```bash
# cd thermal-ai-kit/ui
# npm create svelte@latest .
# npm install
# npm run dev
```
A suitable `Dockerfile` for production builds will need to be created based on the SvelteKit adapter used (e.g., `adapter-node` or `adapter-static`).
